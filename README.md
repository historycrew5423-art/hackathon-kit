# hackathon-kit

两个人加一堆 agent 一起打 3D 网页游戏黑客松用的手册：规矩、口令、命令。目的是不在和“游戏好不好玩”无关的地方浪费比赛时间。

完整方案：[超级 skill 方案（讨论稿）](https://github.com/historycrew5423-art/3d-/blob/main/docs/09-超级skill方案-讨论稿.md)

## 现在建到哪

- 第 0 步 收拾现场：做了一部分，搁浅分支的去留等两个人定
- 第 1 步 骨架和入口：建好了，等两个人各自用自己的工具试一遍
- 第 2 步 上线命令：还没建
- 第 3 步 开赛命令和收件口：还没建
- 第 4 步 素材入库、试衣间、素材库和声音库：还没建
- 第 5 步 底座：还没建
- 第 6 步 经验卡、提示词配方、口味档案：还没建
- 第 7 步 演习、第 8 步 赛前体检：还没到

## 怎么用

1. 把这个仓库克隆到电脑上，用你的工具打开这个文件夹。
2. 对 agent 说：**开工**。
3. 它会先问你是队长还是队友（只问一次），然后告诉你现在的情况和它打算做什么。你点头，它才动手。
4. 干完了说：**收工**。

平时用的口令：

- “开工”：同步、读现状、复述、认领
- “收工”：交活、写五行小结、放开认领
- “定了：……”：记一条决定
- “反馈：……”：记一条试玩反馈
- “对表”：谁在做什么、定了什么、离下一个时间点多久
- “交接”：活做到一半换一个 agent

## 各个工具怎么接进来

- **Cursor、Codex**：自动读 `AGENTS.md`。
- **Claude Code**：自动读 `CLAUDE.md`。
- **Kiro**（桌面版和网页版）：自动读 `.kiro/steering/hackathon-kit.md`。
- **WorkBuddy**：它会不会自动读上面这些文件，还没试过。读不到的话，开头对它说一句：“先读仓库里的 skill/SKILL.md，照它做。”
- **网页版 GPT、Claude**：进不了仓库。用“开场白”和“收口”，见 [skill/phases/chat-tools.md](skill/phases/chat-tools.md)。

这些入口文件都只有一句话：去读 [skill/SKILL.md](skill/SKILL.md)。规矩只写在那一页。

## 试一遍（第 1 步的验收）

两个人各自用自己的每个工具打开这个仓库，说“对表”。每个工具答出来的“已定的事”和“现状板”应该一样。不一样，或者哪个工具没照做，记一条“反馈：……”。

## 目录

- `skill/SKILL.md`：总入口，一页
- `skill/phases/`：每个阶段一页
- `kit/kit.mjs`：命令。`node kit/kit.mjs` 列出全部。只要装了 Node 18 以上就能跑，不用装别的
- `kit/test.mjs`：命令的自查，`node kit/test.mjs`
- `state/`：这个仓库自己的现状板、已定的事、小结、反馈
- `template/`：比赛仓库模板
