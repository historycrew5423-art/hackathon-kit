# 交接：活做到一半，换一个 agent 接

## 交出去的一方

1. 把手上的改动提交并推上 GitHub，哪怕没做完。没做完的在小结里写清楚。
2. 运行：

```text
node kit/kit.mjs done --who <人> --agent <工具名> --handoff --did "做到哪" --half "哪些改了一半" --verify "怎么验证" --next "下一步" --pitfalls "有什么坑"
```

五行都要写实话。“改了一半的”最重要，接手的人最容易在这里踩坑。

加了 `--handoff`，认领不会放开，别人不会趁这个空当来动同一块地方。

## 接手的一方

1. 运行 `start`，读“最近的收工小结”里带“（交接）”的那一条。
2. 用三句话向人复述：上一个做到哪、哪里改了一半、我接下来做什么。等人点头。
3. 运行 `claim`，任务和目录照上一个的写。然后动手。

## 换人不换活

队长的活交给队友（或者反过来）：交出去的一方正常 `done`（不加 `--handoff`），在 `--next` 里写明交给谁。接手的一方 `claim`。
