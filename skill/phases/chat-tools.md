# 只能聊天的工具：开场白和收口

网页版 GPT、Claude 这类工具进不了仓库。它们聊定的事，不贴回仓库就不算数。

## 开始聊之前

让一个能跑命令的 agent 运行：

```text
node kit/kit.mjs opening --who <人> --agent <工具名> --question "这次想聊的问题"
```

把打印出来的整段贴给聊天工具。里面有已定的事、两个人各自在做什么、这次的问题，还有收口的格式。

## 聊完

对聊天工具说：**收口**

它会输出一张决定卡，长这样：

```text
【决定卡】
- 定了：一局九十秒，时间到按分数算输赢
- 定了：主角只有奶蛙一个
- 反馈：开场对话太多，想直接开打
```

## 贴回仓库

把决定卡存成一个文件（比如 `card.txt`），让能跑命令的 agent 运行：

```text
node kit/kit.mjs ingest --who <人> --agent <工具名> --source GPT --file card.txt
```

每条“定了”会变成一条已定的事，每条“反馈”会进反馈表。贴回之前人先看一眼，不同意的那行删掉。

## 口头说定的事

两个人当面或者在微信里说定的事也一样：对任何一个 agent 说“定了：……”，让它记进仓库。

## 聊天里用到的图

聊天里发过的参考图、视频截图，存进仓库的 `refs/` 目录，之后只按路径引用。别的 agent 拿不到聊天里的图。图片的宽和高都不能超过 2000 像素。
